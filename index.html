THE PROCESS

How Does It Work?

Your password is checked using a privacy-focused method called k-anonymity.

01
🔑

Enter Password

Enter the password you want to check in the password checker.

02
🔐

SHA-1 Hashing

Your browser converts the password into a SHA-1 hash.

03
🌐

API Request

Only the first five hash characters are sent to the HIBP API.

04
🛡️

Security Result

Your browser matches the hash and displays the exposure count.

ABOUT THE PROJECT

Protect Your Digital Identity

PasswordGuard is an educational password security project designed to help users check whether their passwords have appeared in known data breaches.

It uses the official Have I Been Pwned Pwned Passwords API and the k-anonymity model to perform privacy-conscious checks.

A password not found in the database is not guaranteed to be completely secure.
